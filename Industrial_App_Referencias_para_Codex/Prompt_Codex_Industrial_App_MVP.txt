4. TRABAJO DE TRANSPORTE (T.W.): selector 'Método base / Método propuesto', rutas editables con origen-destino, intensidad kg/día, viajes/día, distancia m; calcula T.W. por ruta = intensidad * distancia (kg·m/día), distancia con carga = viajes * distancia, tiempo = viajes * (2 * distancia / velocidad + tiempo de carga/descarga), permitiendo editar velocidad y tiempo de carga. Incluye totales y comparación de ambos métodos. NO confundas kg·m con metros recorridos.
5. GRÁFICAS SHA: diagrama Pareto de tiempos por causa, dispersión distancia-intensidad (X = distancia m, Y = intensidad kg/día) para rutas de ambos métodos y barras comparativas de indicadores base vs propuesto. Los gráficos deben usar los datos editados, no una copia estática.
6. EXPORTACIÓN: descarga un archivo XLSX con hojas de parámetros, materiales, 7R, P-Q, rutas y cálculos, resumen y Pareto. Genera el Excel desde el estado ACTUAL de la aplicación con io.BytesIO y pd.ExcelWriter(engine='openpyxl'). Nunca exportes tablas obsoletas ni resultados de un ejemplo BITS.
